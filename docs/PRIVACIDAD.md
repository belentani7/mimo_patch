# Privacidad

## Qué se recoge

- Nada por defecto: el sitio es estático y no envía datos a un servidor propio.

## Qué no se recoge

- Datos personales de visitantes sin consentimiento explícito.
- Credenciales, tokens o claves en el repositorio.
- Analítica de terceros que perfile.

## Base

El repositorio no incluye backend de analítica. Si en el futuro se añade, debe declararse
aquí con nombre de proveedor, finalidad y forma de desactivarlo.
